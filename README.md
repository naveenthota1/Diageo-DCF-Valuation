# Diageo PLC (DGE.L) — DCF Valuation Model

Full discounted cash flow valuation of Diageo plc with 5-year explicit forecast (FY26–FY30), 
WACC calculation, 25-scenario sensitivity analysis, and comparable companies cross-check.

## Summary

- **DCF-implied target:** £19.89 (19% upside vs current £16.65)
- **Comps-implied target:** £14.97 average of EV/EBITDA and EV/Revenue methods
- **Blended target:** £17.43 (+4.7% upside)
- **WACC:** 7.26%
- **Recommendation:** HOLD / BUY on recovery

## Methodology

Historical P&L (FY21–FY25) sourced from Diageo annual reports. 5-year forecast built around management's "Accelerate" cost programme assumptions (~$625m savings over 3 years). WACC derived using CAPM, UK 10Y Gilt as risk-free rate, Damodaran UK Equity Risk Premium. Comparable companies: Pernod Ricard, Brown-Forman, Constellation Brands.

## Key assumption

The DCF rests on EBIT margins recovering from the depressed 21.4% in FY25 back to roughly 29.5% by FY30 as the Accelerate programme delivers. Terminal value represents 81% of 
enterprise value, so WACC and terminal growth assumptions dominate the valuation output. The sensitivity grid shows a defensible range of £13 to £30.
